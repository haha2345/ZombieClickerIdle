# 丧尸点击放置：同类游戏调研与借鉴建议

检索日期：2026-09-30。适用项目：`ZombieClickerIdle`。

**优先参考 Grow Survivor 和 Tap Tap Gun 的射击成长，用 Clicker Heroes、Tap Titans 2、Idle Slayer 补强推进节奏；Melvor Idle 和 Dead Ahead: Zombie Warfare 用作局部机制参考。**

本次阅读官方商店说明、官网与开发者帮助资料，未安装这些游戏进行实机试玩，也未逐一验证其完整后期。下文把可核实的作品信息与针对本项目提出的方案分开。相似度和优先级为设计判断，不是用户留存或商业效果数据。

## 2. 针对本项目最有价值的六项借鉴

下面全部为**本项目的新设计建议**，不是这些游戏或原录像的逐条规则。

### A. 让换枪改变操作感

参考 Tap Tap Gun 的枪械收集方向，保留录像的枪系分类：

- 手枪：单次伤害清楚，点击反馈利落，适合主动爆发。
- 步枪：连续射击和稳定输出，适合挂机。
- 霰弹枪：近距离／群体优势，等引入多敌人时再体现散射价值。

M1 先做当前手枪和一把能实际装备的新枪，验证开火节奏、伤害和音效表现都发生变化。暂不同时加入弹药、换弹、自由移动和大型技能树。霰弹群体效果留 M2。

### B. 把“刷资源”和“挑战 Boss”做成可切换目标

参考 Clicker Heroes 的区域成长结构，本项目可以提供“稳定刷已通关关卡”和“挑战当前 Boss”两种模式。

Boss 失败后，显示：还差多少输出、哪项升级当前可完成、哪个已通关关卡更适合获取所需金币。刷关界面显示预估基础金币／分钟；自动攻击在已通关关卡稳定运转，未首通 Boss 仍由玩家主动发起挑战。

这样金币积累与下一次挑战直接相连。不要让失败后的唯一可见动作是看广告，也不要用无解释的战力门槛代替战斗反馈。

### C. 章节首通带来一种新能力

参考 Idle Slayer 的逐步展开，本项目延续现有 M1 解锁草案：

| 节点 | 新能力 | 后续目标 |
|---|---|---|
| 第一轮主线完成 | 黑市商品可买 | 得到一把实际能穿戴的新武器 |
| 技能与装备入门完成 | 输出提升与熟练度成长 | 挑战下一只 Boss |
| 第 3 关首通 | 永久自动开火 | 离线准备并配置下一个成长目标 |
| 第一章后段 | 新枪系或第一只宠物 | 应对有特点的敌人 |

这些不是原作已验证的解锁顺序。教学顺序和关卡数仍以试玩调整；首版不急于加入多个小游戏、村庄或其他大型支线。

### D. 熟练度门槛要能被玩家主动解决

借鉴 Melvor Idle 的技能相互支撑，复刻录像中“霰弹熟练不足”的门槛时，还要给出获得该熟练度的具体路线。

一种方案是：基础枪不要求该枪系熟练度，成功战斗积累熟练度，再解锁高级枪。装备详情直接显示“差多少、如何训练、练成后增加什么”。第一把霰弹枪不能要求只有装备霰弹枪才能获得的高熟练度，否则形成无法开始的循环。

M1 只做必要枪系的熟练度；医疗、技术和制作成长留到有明确用途时再实现。

### E. 用敌人差异制造换装理由

参考 Dead Ahead 的敌人多样性，本项目可在固定战斗结构中逐渐加入：

| 敌人建议 | 玩家可见特点 | 有价值的应对 |
|---|---|---|
| 普通白领 | 单体、低防护 | 教学与稳定金币来源 |
| 护甲感染者 | 减伤提示和明显护甲外观 | 穿透类武器／技能 |
| 快速感染者 | Boss 时间或接近节奏更紧 | 主动爆发 |
| 群体感染者 | 一组低生命目标 | 霰弹／范围攻击 |
| 携物感染者 | 固定材料图标 | 为明确装备目标刷材料 |

“单体普通＋单体 Boss”先完成；其余留 M2。不要为了借鉴 Dead Ahead 同时增加巴士、单位编队和战术部署。

### F. 宠物和技能对应不同游玩方式

参考 Tap Titans 2 的构筑思路，但压缩成两个清楚方向：

- 主动方向：点击爆发、Boss 输出、短时间技能增益。
- 挂机方向：稳定自动攻击、离线效率、资源积累。

同一关卡可以通过不同配置完成，玩家不必为一个全局最高战力数字买齐所有宠物。宠物先做各自一项明显用途，不同时展开几十个相乘加成和多个成长币种。

## 3. 广告可以借鉴什么

### 可核实的参考

Idle Slayer 官方 press kit 明确说明没有强制广告打断冒险。这支持“基础成长可独立完成，广告是主动选择”的产品方向；该页面没有给出当前各广告奖励的完整细则。[Idle Slayer 官方资料](https://idleslayer.com/press-kit)。

Game Hive 在 **2018-05-08 的 Tap Titans 2 v2.8 路线图**中介绍过视频奖励妖精，包括激活主动技能、短时降低升级费用和恢复部分法力。这里是历史机制参考，不是对当前版本广告的确认。[开发者历史说明](https://gamehive.com/blog/tap-titans-2-devlog-21-roadmap-for-v28-and-beyond/)。

### 本项目建议：把已有广告点做成世界中的补给

“无线电补给”“物资箱”“战术增援”可以替代分散的纯功能按钮。它们是入口表现，仍然使用已有的金币、罐头、刷新等奖励，不另造一种货币或重复增加次数。

| 情境 | 可选择的广告 | 保留的普通路线 |
|---|---|---|
| 刚回到游戏 | 领取基础离线收益后，选择追加奖励 | 免费基础结算正常完成 |
| 黑市差少量金币 | 无线电金币补给，清楚显示将获数量 | 显示刷关收入与当前可买商品 |
| 宠物差罐头 | 物资箱提供罐头 | 挑战、任务和黑市来源仍能获取 |
| Boss 刚失败 | 一次重试增援，明确增益和持续范围 | 自由重试或刷关提升，不直接发胜利奖励 |
| 需要换黑市商品 | 补充有限刷新次数 | 保留基础刷新与已有商品选择 |

优先只验证金币补给、离线追加和黑市刷新三种资源点。自动开火提前体验放在明确的解锁节点；其余既有广告方案继续留后期。

当前规划“10 个广告入口、全局每日最多 12 次”只是 v0.1 草案。本次研究没有证明它们是最优配置，也没有发现这些参考游戏统一使用这组额度。

不新增强化保底广告或强制视频解锁必需物品。观看失败、没有广告库存和用户拒绝观看时，正常成长仍然可达成。

## 4. 第一版只吸收这四个变化

1. **下一把枪有明确目标和不同射击表现**：从金币、熟练度到购买和实际穿戴完整走通。
2. **Boss 失败后给出可执行的升级路线**：回到已通关关卡刷资源，再挑战。
3. **首通解锁永久能力**：每个早期关键任务都改变玩家能做的事情，自动开火有正常解锁路径。
4. **广告奖励集中为可选补给**：先验证少量核心资源入口，展示明确收益并保持非广告路径。

M2 再加入武器材料／图纸、宠物构筑和敌人变体。M3 的研究室、竞技场和进化仍待录像或独立玩法验证。

## 5. 值得观察的试玩记录

以下是后续观察清单，不是本次已经完成的试玩：

| 游戏 | 观察任务 | 记录什么 |
|---|---|---|
| Grow Survivor | 完成第一轮武器成长与一场挑战 | 材料如何产生目标、制作与强化是否重复、失败后的路线 |
| Tap Tap Gun | 获得下一把枪 | 枪的节奏、反馈、收藏动机、替换过程 |
| Clicker Heroes | 完成早期升级并遇到卡关 | 主动／自动的关系、金币花费和 Boss 压力 |
| Tap Titans 2 | 比较两种可用构筑 | 输出与操作频率差异，技能／宠物的角色 |
| Idle Slayer | 完成前几组目标与一次回归 | 解锁顺序、离线后给出的下一目标、可选广告位置 |

每次记录：当前目标 → 输入操作 → 收益 → 可买升级 → 新目标；广告记录实际奖励、时长、冷却、失败和次数扣减。不以旧评论或商店含广告标记代替这些证据。
