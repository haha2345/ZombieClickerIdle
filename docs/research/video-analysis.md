# 游戏逐帧解析与复刻评估

**结论：可以复刻视频中可见的战斗、成长与界面表现，适合制作一个二维竖屏点击／放置游戏。视频不足以还原完整原作的后期内容、经济公式、服务端与隐藏规则。**

## 2. 视频中的玩法结构

玩家固定在画面前景，点击攻击迎面而来的敌人，通过击杀获得金币并推进计数任务。金币用于学习／升级技能、买装备和强化；武器装备受熟练度限制。Boss 是单独的限时挑战。

核心循环可概括为：

**点击攻击 → 击杀与金币 → 任务／赏金结算 → 技能、武器成长 → 挑战 Boss。**

“推进天数、解锁自动开火、获取离线收益”是界面指向的后续成长方向。录像始终处于“惊变第 2 天”，没有展示 Boss 胜利和进入下一天的完整过程。

这个游戏的交互重点是攻击频率、数值成长和功能入口。录像没有出现玩家自由移动、瞄准选择身体部位、闪避、换弹、弹药管理或多角色编队，因此复刻可见内容时不需要先加入这些系统。

## 4. 战斗和动画逐帧观察

### 普通战斗

画面可拆为固定背景、前景女枪手、中央敌人、枪口特效、命中烟雾／碎屑、伤害数字和 UI。敌人有连续的摇摆、受击和死亡画面；人物开火时有局部变化。枪口闪光常只被录像捕获到几帧，配合抛壳、绿色命中特效与白色飘字形成射击反馈。

部分连续帧中，旧敌人的死亡特效尚未消失，新敌人已经出现并开始掉血。说明复刻时应该让“结算与刷新敌人”和“死亡特效结束”分开处理，避免一个长死亡动画阻塞点击。

普通击杀金币样本：

| 原金币 | 击杀后 | 差值 | 附近时间 |
|---:|---:|---:|---|
| 141 | 173 | +32 | 2.8 秒 |
| 173 | 205 | +32 | 5.1 秒 |
| 205 | 237 | +32 | 7.6 秒 |
| 237 | 269 | +32 | 10.1 秒 |
| 269 | 949 | +680 | 12.7 秒，计数达到 20 |

界面此前显示“赏金 680”，且抓捕计数满后重置，支持“累计击杀周期结算赏金”的判断。最后一次 +680 是否包含普通击杀款，录像不能确认。主线任务领取和周期赏金也应作为独立事件核对，不能把 680 当成每只怪的奖励。

攻击频率显示在 0–4 次／秒之间变化；可见普通伤害为 178，暴击率显示 0.0%。无法据此确定点击上限、冷却算法、攻击公式或所有敌人生命值。

**录屏里的白色点击圆圈跟随鼠标操作，可能是录屏点击提示；鼠标指针、顶部宿主栏也不应直接算作游戏美术。**

### Boss

食人花详情标示生命 18250，手枪减免 0%、步枪减免 10%、霰弹枪减免 5%；奖励显示开火经验 100、金币 4900。奖励只被展示，没有实际结算。

进入战斗后换成室外废墟背景，Boss 在中央，随时间呈现向前接近／放大的变化。约 73 秒剩 19.5 秒、生命 98.5%；约 86 秒剩 6.5 秒、生命 62.0%。随后点击撤退，出现“撤退将会失败”确认，最终弹出失败界面。

这次失败是**主动撤退**，没有录到倒计时归零失败，也没有录到胜利。入场过渡中曾出现超过 100% 的生命文字，不能把这种瞬间状态作为正式生命规则照搬。

这种画面效果可以用二维素材、位置／缩放变化和特效叠层重做。原作是否使用三维模型、骨骼动画或序列帧，单凭录屏不能确定。

## 5. 成长系统与数值门槛

### 技能与装备

技能分为手枪、步枪、霰弹枪、医疗、技术。录像展示的“手枪入门”Lv19：攻击力 117、战术能力 +19、手枪熟练 +19，升级费 4615。这里的数值不能直接证明最终战力的加法公式。

仓库容量为 4/20，可按装备、材料、资料、特殊和白／绿／蓝／紫／橙品质筛选。可见装备状态和强化状态是分开的。

| 项目 | 视频证据 | 复刻时的规则含义 |
|---|---|---|
| 已装备格洛克 +1 | 攻击力 +42，手枪熟练要求 5，强化效果 +10 | 当前输出来自已装备物品，而非背包最高攻击物品 |
| 格洛克强化 | 显示成功率 48.2%，费用 160 | 需要成功／失败、扣费、提示等状态；录像没有展示失败结果 |
| 霰弹枪“清剿”初始 | 攻击力 +180，要求霰弹熟练 90，强化费 800，成功率 50.0% | 强化和穿戴分别检查条件 |
| “清剿”强化成功 | 变为 +1、攻击力 +190，金币减少 800，下一次成功率显示 48.2% | 可验证本次强化增加攻击力 10；不能外推所有强化等级曲线 |
| 尝试穿戴“清剿” | 显示“霰弹熟练不足” | 攻击力更高也可能暂时无法使用 |
| 点射残页 | 上／中已有，缺少下册，合成按钮提示缺少下册 | 碎片收集、合成、学习是不同步骤 |

### 黑市

首次可见商品价格包括突击队 380、创伤手册（中）1920、步枪入门 475、格洛克 760、技术入门 950。刷新剩余 10 次，视频入口标示加 20 次。黑市升级预览费用为 1800，列出罐头、武器、秘籍等新商品。

录像没有录到刷新后商品变化、购买成功、刷新次数消耗或黑市升级成功，因此价格表可参考，商品池概率与更新逻辑必须另行设计。

### 宠物、签到与离线

宠物包括离线收益、免费金币、会员积分、自动开火爆发时长、稀有商品概率和 Boss 战力等加成。欧比升级需要 10 罐头，当前 0 个；界面预览离线收益 +1%→+2%。免费入口显示视频领取罐头 ×5、今日剩 3 次。

离线界面显示“120 分钟／120 分钟”，战绩金币 157964、黑市刷新次数 +40、建筑收益与进化点数为 0。这里能确认的是**这一次弹窗的显示值和广告领取门槛**；没有观察实际离线、收益计算过程或领取成功，不能据此确定全局离线上限、倍率及存档防作弊规则。

签到、广告次数的现实日期与“惊变第几天”的游戏进度应分别建模。录像未证明二者使用同一个时间单位。

## 6. 美术与界面怎样重做

视觉风格是带粗轮廓、明暗块面与末日漫画感的高清二维画面。UI 使用破损纸张、胶带角、金属底栏、警戒条和金色按钮。角色画面与菜单都具有统一的粗线、磨损纹理和色彩体系。

建议拆分资产：

1. 走廊与室外废墟两张背景。
2. 主角持枪立绘、开火姿态；普通白领、食人花 Boss 的动作素材。
3. 枪口闪光、命中、死亡烟雾／爆裂、抛壳。
4. 纸张面板、按钮、底栏、品质框与状态条。
5. 武器、秘籍、宠物、奖励图标。

截图可提供构图、配色与动作参照，但包含遮挡和 UI，没有透明通道，不能直接恢复完整人物、敌人背面和背景被遮挡区域。

若进入制作阶段，按用户要求：**先用录像帧作为图生图参考，使用 imagegen 重建风格一致的分层素材；角色／敌人的动态素材用 Grok CLI 生成视频，再抽帧制作 Sprite sheet。** 动态素材需要检查形体一致、镜头固定、位置对齐、循环接缝和背景处理；不能认为生成视频直接抽帧就一定适合游戏。伤害数字、计时条与按钮等界面变化由程序驱动。

## 7. 复刻难度与边界

| 范围 | 可行性 | 主要工作 |
|---|---|---|
| 点击伤害、生命条、普通击杀、金币与任务 | 高 | 明确攻击节奏、结算顺序与重复点击处理 |
| 装备、技能、强化、熟练度门槛、背包 | 高 | 数据表、状态流转、存档与提示 |
| Boss 计时、入场、撤退、失败 | 高 | 战斗状态与动画反馈 |
| 自动开火、离线收益 | 可以实现 | 视频未验证具体公式，需要定义自己的规则 |
| 画面构图、材质、菜单与射击反馈 | 可以接近 | 工作量主要在统一美术与连续动画质量 |
| 原作全部商品、掉率、长期养成 | 无法只靠本视频还原 | 缺少不同进度、完整奖励与经济证据 |
| 世界 Boss、竞技场、研究室等后期功能 | 只看到入口 | 需继续录制实际流程，或自行设计 |
| 榜单、广告、账户与服务端 | 可单独建设 | 录像无法反推接口、服务器行为与平台约束 |

**主要难点不是“打怪按钮能否做出来”，而是保持美术统一、让成长曲线持续有目标，以及复原视频没有展示的状态。** 当前素材适合定义第一版范围，不适合直接照推完整原作。

## 8. 可验收的第一版范围

建议第一版限定：一个主角、一个普通敌人、一个 Boss、两张战斗背景；技能、黑市、仓库与战斗四类主界面。

先贯通这条流程：普通攻击 → 击杀金币 → 20 次任务与黑市解锁 → 获得可装备的新武器 → 技能／强化成长 → Boss 胜利 → 进入下一阶段 → 自动攻击与离线结算。

其中“Boss 胜利后的推进、自动开火、离线公式”属于**建议补齐的玩法**，不是本录像已验证的实现。初版应有清楚的规则表，以便调整数值，后期入口等完整内容验证后再加。

验收关注：金币只结算一次；切换菜单不重复掉落；未装备物品不改变伤害；熟练度与金币不足有正确提示；Boss 撤退与胜利分别结算；重开后装备、任务和解锁状态可恢复。

本次完成视频分析与查看资料，尚未创建游戏原型或生成新美术。
