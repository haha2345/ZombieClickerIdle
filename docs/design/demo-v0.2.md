# 末日信标 · v0.2 可玩演示

2026-09-30。用户授权：将录像玩法与同类游戏灵感组合成能支撑5小时以上的小品级演示。本文描述当前运行行为，不把原录像未玩到的后期当作已验证原作。

## 核心体验

清理感染者 → 金币/零件/残页 → 训练、买枪、练习熟练度与强化 → 25秒首领 → 首次通关解锁区域与永久能力 → 自动/离线准备 → 携带合适伙伴继续挑战。

鼠标点击或按住战场，空格射击，B集中火力，F全屏。没有强制广告或必需付费。首领失败保留全部资源；回到地图任一已解锁关卡回收，准备好再挑战前线。战斗面板显示首领血量与按每秒3次点射估算的时间，帮助判断应升级什么；估算不代替暴击与爆发的实际战斗。

## 内容规模

- 六片区域，每片4关，共24关；每关清理目标、25秒首领、首次奖励、下一路线。每片有短篇无线电背景。
- 10把枪、3枪系熟练度、每枪最多10级确定性强化。购买和装备是不同动作，强化可用于未穿戴的已拥有枪。
- 射击训练最多120级，首领战术最多30级。演示常规通关约训练54级；满训练不是演示完成条件。
- 3种套册学习，每种5级；上中下册各一份，普通击杀每9次轮流掉落残页。
- 3位伙伴各10级：欧比资源+4%/级，克劳德暴击+1.5%/级，斯帕克自动伤害+6%/级；只携带一位的效果生效。
- 3条永久研究：伤害+5%/级、收益+6%/级、离线上限+30分钟/级。研究点来自有限首通/成就，全部路线同时满级不是当前完成目标。
- 8项可单次领取成就、4类击杀图鉴；每20次普通击杀发额外金币赏金和1罐头。
- 到24关有明确通关结果，可继续枪柜/成就收集；没有转生、多人大系统或无限随机章节。

主要节点：第1关左轮/补给，第3关永久自动/黑市物资/欧比，第5关霰弹与敌人变体，第7关克劳德/法玛斯，第8关研究，第9关护甲，第11关斯帕克，第12关先锋步枪，第15关清剿者，第18关精确步枪，第21关曙光原型，第24关点亮信标。

## 5小时目标与验证范围

模拟直接调用与实时会话相同的domain规则，每秒推进并产生实际射击、暴击、普通死亡、奖励、购买、强化、熟练度、伙伴/手册/研究升级及25秒首领挑战。包含生效的强化后输出，不只检查解锁时间表。

策略每3秒检查购买和升级，会提前强化未穿戴的新枪，比较可用枪输出，保留接近可购新枪的金币；回收时用欧比，首领前按实际DPS选择已培养伙伴。首领准备评估包括当前装备、护甲/植物克制、暴击和爆发；无外部无限资源注入。固定随机种子使结果可复现。

脚本对全部策略可完成及快速策略至少5小时进行断言；失败不会报告验收通过。每秒3次输入较慢，约11.7小时，需要放置积累；快速基准约6小时。广告不是必需路径，三次补给缩短少量积累。

**这些是规则模拟，不是五小时人工试玩。**它包含重复回收/训练/装备准备的累计成长时间，不等同于五小时独立剧情/地图美术，也不是对所有玩家最快策略的严格下限证明。没有模拟关页多次离线、所有混合补给排列或全球最优策略；离线安排、构筑和实际操作会改变时间。现版本中段仍存在长积累区间，长期趣味需要真实玩家反馈，不能由完成时间代替。

## 资源与经济

敌人基础HP为58×1.72^(关卡-1)，金币16×1.55^(关卡-1)；护甲HP×1.2、疾行×0.8、群体×1.3。Boss基于520×1.98^(关卡-1)和分区系数；24关HP单调增长，换区保留部分休整而不会降血。

训练成本420×1.315^(等级-1)，伤害×1.13/级；强化伤害+12%/级，成本15×1.9^强化等级。高级枪购买条件是对应关卡首通，装备条件另需对应枪系熟练度。精确数值与完整内容见src/content/demo.ts和src/domain/systems/demo.ts。

离线不战胜首领，回收最高已通关区域估算自动资源率的80%。基础上限2小时，研究最多6小时；只产金币/零件，不补熟练度/残页/罐头/普通击杀数。基础领取免费；未领取批次受库存上限约束，追加只对已领取批次给一份。自动暂停时不产生新的离线收益。

## 美术与界面

一张背景、丧尸和食人花透明图均根据录像帧由imagegen图生图生成。六区域复用同一走廊，敌人变体复用丧尸并通过颜色/属性提示。Grok CLI尝试未返回视频，当前没有角色Sprite动画；受击数字和HP为程序界面反馈。来源记录、尺寸和哈希在art/source/imagegen及art/catalog.json。

桌面三栏：区域线路、竖屏战场、七个成长面板。390px手机战场优先，底部固定菜单进入成长页面与返回战场；没有横向溢出。导出/导入本地JSON、坏档保护和确认新游戏均可操作。
