# v0.3：画面内界面、主动首领挑战与渐进开放

本文件记录2026-09-30的实现基线，替代 v0.2 中静态角色、三栏界面、第三关直接自动及旧时长的描述。沿用六区24关、10枪、3伙伴、3手册、3研究、8成就的小品演示范围。

## 开局与首领

新档只出现资源、当前任务、敌人生命、清理目标、未点亮的挑战按钮及“战斗”入口。全部处于同一个竖屏游戏表面内。成长面板、帮助、广告、存档和离线结算也在这个表面内弹出。桌面居中竖屏，手机适配全屏；F 全屏包含界面。

击杀5只普通感染者，立即完成“先把门口清干净”并发128金币。显示“已具备挑战资格”，底部挑战按钮呈金色发光，预览高额首通奖励。**不会自动切换Boss**，玩家可继续清理，或主动点按钮挑战。

主动挑战后切换独立楼顶场景及锥帽暴君。1.8秒入场警报结束后开始12秒逼近，血量低于35%加速；到达近身线即退回普通怪，资源保留。后续首领基础时间25秒，植物首领使用温室与食人植物。集中火力解锁后增加8秒伤害，并把正在逼近的首领击退2秒。

第一位首领本体奖励560金币、12零件、3罐头、3研究点；“守住第一次接近”任务再给320金币和12零件。因此新档首次击败合计 **880金币、24零件、3罐头、3研究点**，自动到账并显示胜利横幅，同时开放射击训练。后续首通金币按本关基础收益×35及回收倍率成长，任务奖励另加；已首通关卡不能重复刷首通奖励。

## 功能顺序和时间

解锁由击杀数量与首通数触发，两者同时满足。时间不是等待锁；玩家决定挑战时机，暂停、失败、阅读、挂机会改变墙钟时长。表中时间来自每秒3或5次输入、及时购买升级和主动挑战的共享规则模拟，不是人工试玩时间。

## 动画与素材

imagegen 图生图拆出主角，生成不含人物的走廊、楼顶与温室背景。真实Grok CLI `reference_to_video` 输出四段视频，ffmpeg抽帧，再去色键并按固定格子打包，Phaser播放射击、普通怪步行、暴君重步和植物张合。伤害和子弹状态驱动主角动作，动作不会额外制造伤害。

当前主角开枪有抬枪后坐、上身跟随与马尾滞后甩动；胸臀随身体的幅度较轻，还没有原参考游戏那种明显的独立软组织摆动。加强幅度的第二段视频因传输失败未交付，当前保留验收过的第一版。视频有少量轮廓漂移及边缘残色，属于演示资产，尚未达到正式商用动画精修水平。

## 五小时验证和存档

最终共享规则模拟：3次输入无广告10.40小时；5次输入无广告5.22小时；3次后期补给5.03小时；3次前期补给5.23小时。四条策略都自然首通24关，快速策略至少5小时断言通过。这是刷怪、积累、准备与推进的成长时长，不是5小时独立场景、剧情或已完成5小时人工游玩，也不穷举所有优化策略。

保持原独立存档键，内容schema3。schema2存档保留资源、装备与进度并迁移；已拥有的部分系统保留资格，旧任务不补发重复奖励。体验完整渐进开局需自行在画面内“存档”导出后选择两次确认的新游戏。开发检查只使用独立`:test`键。

激励广告仍是明示的3秒本地模拟，取消不发奖、完成后手动领取，去重、冷却与每日额度已实现。没有接入真实广告SDK。
