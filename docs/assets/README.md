# 美术与动画工作流

## 现有参考

关键帧存放在 `art/source/references/`，原始录像仅保留本地。截图来源与时间戳见 `art/catalog.json`，只作为构图、色彩和动作证据，原始参考帧不会直接加载为游戏人物。

录像包含宿主栏、鼠标、点击提示、遮挡和压缩；不能把完整截图直接当作透明角色资源。广告里的其他游戏不作为本作美术参考。

## 用户要求的生成流程

1. 从已有录像帧选择参考；用 imagegen 图生图生成风格一致的背景、人物、敌人和界面素材。有参考图时不直接改用文生图。
2. 角色／敌人和需要制作的动态素材用 Grok CLI 做视频，再抽帧制作 Sprite sheet。
3. 抽帧检查镜头、人物比例、站位、形变、遮挡、循环首尾与透明背景。背景移除／图片编辑仍使用 imagegen；不要未经要求用其他工具替代。
4. 为成品记录来源、参考帧、提示词、生成工具、尺寸、帧数、帧率和哈希。
5. 源图／视频放 art/source；合格成品放 public/assets；通过 Phaser 实际播放验证后再声称已接入。

建议首批资产：两张背景、主角持枪／开火、白领行走／受击／死亡、食人花入场／攻击／受击、枪口／命中／死亡特效，以及面板、按钮和武器图标。

历史 v0.2 用 imagegen 图生图生成一张场景与两类透明敌人，出处见 art/source/imagegen/2026-09-30-provenance.md。当时 Grok CLI 视频任务未返回；随后 v0.3 完成视频生成、抽帧和接入，见下方当前资产说明。
