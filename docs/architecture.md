# 演示架构与接入边界

`main.ts → App.vue → gameSession`。Vue 和 BattleScene 通过同一个会话发出动作，domain 校验、扣资源、修改状态，两种显示层读取同一结果。Phaser 不自行结算金币或首通。

## 规则与时间

`domain/systems/demo.ts` 包括战斗、首通、穿戴／强化、资源、手册、伙伴、研究、成就、离线与补给事务。无 Vue、Phaser、localStorage 或 SDK 依赖。伤害、敌人血量、掉落与内容在 `content/demo.ts`。

战斗以最大50ms规则子步推进，manualCooldown和自动射速分离，敌人死亡后等待0.55秒生成下一个。Boss 开局12秒、后续25秒，1.8秒入场后开始逼近，到达失败退回刷资源，首通后直接解锁下一关。普通击杀与首领奖励分别结算，死亡对象不能重复发奖。

会话实时时钟每50ms更新，单次最大补偿1秒；标签页隐藏时保存，回来进行离线回收，而不是把浏览器后台节流造成的长dt直接注入战斗。广告模拟中暂停战斗；普通成长面板中自动继续。存档／补给／帮助弹窗阻断手动战场热键，避免在文本输入中意外开火。

## 存档

键 `zombie-clicker-idle:save:v1`，内容schemaVersion3；schema2对象通过normalizeSave迁移保留资源与进度，已完成旧任务标记已领取。每5秒及pagehide保存。读取／JSON／状态校验失败保留原始文本并暂停覆盖，界面显示恢复入口；导入先校验，失败保留当前进度。开始新游戏需两次明确操作，坏档重置前尝试保存recovery副本。

导入校验资源有限且非负、阶段与首通一致、HP范围、枚举、枪械拥有关系、研究／强化／伙伴／手册等级上限、数组和广告结构；不把本地存档当成安全的多人经济或付费凭证。导出为JSON可下载或复制。

基础离线回收300杀且第三关首通开放；使用最高已通关区域、当前武器的估算自动资源率×80%，基础上限2小时，研究最高6小时。它是低成本回收模型，不模拟离线 Boss 首通，也不增加击杀／熟练度／残页／罐头；暂停自动时不结算新的离线收益。未领取批次累加但不会被覆盖，批次总库存受上限约束；基础领取与自愿追加各一次。

## 广告

运行入口配置 `content/demo.ts: DEMO_ADS`，规则事务 `completeDemoAd`。当前是3秒本地模拟器，实际等待结束后手动领取；取消不扣额度不发奖；requestId去重，校验解锁、全局12次／日、入口次数与冷却，追加离线收益需同一批次基础已领取且追加未领取。按UTC日期切换每日额度，冷却跨日保留。

`services/ads/contracts.ts` 保留平台接口，当前不调用真实provider。正式版本必须另外接SDK、平台／服务端时间与凭证验证及持久化事务。M0历史 `adPlacements.ts` 不参与发奖，避免将10个规划入口误当作已实现入口。

## 验证接口

`render_game_to_text` 返回当前真实资源、阶段、敌人血量、首领计时、自动、菜单和离线等。`advanceTime(ms)` 推进同一套规则，供自动化短步骤验证。仅开发模式 `?test` 提供 `window.__demo` 的snapshot／restore／fresh，使用带:test后缀存档，与普通游玩分离。fixture用于后期功能和边界测试，不作为自然新档通关证据。

Node检查直接调用同一套规则。浏览器检查通过实际按钮、画布输入和存档重载验证交互，截图另行目视核对。时长来自策略模拟，不代表人工已玩五小时。Phaser有大chunk体积提示，构建成功；后续美术增长后再评估拆包。


## 同一游戏表面

Vue HUD与画面内浮层位于.workspace，与Phaser共用一个竖屏容器和全屏目标。场景负责背景与独立主角/怪物Sprite；DOM负责可访问按钮、任务与滚动面板。所有可见控制的边界由浏览器检查确认在容器内。独立Sprite动画来自Grok实际视频帧；视觉动作与规则50ms时钟分离，不因多播放一帧而造成伤害。gameMotionState只公开显示帧与位置用于状态观察。
